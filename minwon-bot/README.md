# 민원 도우미 (minwon-bot)

국방부 같은 행정기관에 내는 민원을 **쓰고, 답변을 평가하고, 필요하면 재민원을 쓰는 것**을 돕는 로컬 도구입니다.
내 PC 에서만 열리는 웹 화면(`127.0.0.1`)으로 쓰며, 데이터는 내 PC 의 폴더에만 저장됩니다.

> 작성·평가 보조 도구입니다. 법률 자문이 아닙니다. 제출 전 내용은 직접 확인하세요.

## 지금 되는 것 / 아직 안 되는 것

| 기능 | 상태 |
|---|---|
| 사안 입력 → AI 가 초안과 질의 항목 작성 (정보가 모자라면 먼저 되묻기) | 됨 |
| 내가 쓴 글로 문체 학습, 초안을 고쳐서 내면 그 차이도 학습 | 됨 |
| 제출 전 점검 (반복 회차, 이전 글과 유사도, 하루 한도, 제출 간격, 욕설·협박, 본문 속 개인정보, 지어낸 숫자) | 됨 |
| 받은 답변을 붙여넣으면 질의 항목마다 판정·점수·권고, 법령 링크(확인 필요 표시) | 됨 |
| 미흡한 항목만 겨냥한 재민원 초안 | 됨 |
| 국민신문고에 **직접 제출**하고 접수번호를 기록 | 됨 (복사해서 붙여넣기) |
| 국민신문고 로그인 후 폼 자동 입력·제출, 답변 자동 수집 | **아직 없음** (다음 단계) |
| 답변 후 자동 재민원/자동 종결, 텔레그램·이메일 사후보고 | **아직 없음** (다음 단계) |

## 요금 (크레딧)

- **Claude Code 구독 방식 (기본)**: 이 PC 에 설치되어 로그인된 `claude` 를 호출합니다. 구독 사용량 한도에서 차감되며 **별도 API 크레딧은 들지 않습니다.** 한도가 차면 풀릴 때까지 기다려야 합니다.
- **API 키 방식 (선택)**: 환경변수 `ANTHROPIC_API_KEY` 를 읽습니다. 호출마다 토큰 단위로 과금됩니다(작성+평가 합쳐 건당 약 100~300원으로 추정). 키는 파일에 저장하지 않습니다.

AI 호출은 "초안 작성", "답변 평가", "재민원 초안", "문체 학습", "연결 테스트"를 누를 때만 일어납니다.

## 설치와 실행

필요한 것: [Claude Code](https://claude.com/claude-code) 설치와 로그인(구독 방식일 때), Go 1.24 이상(직접 빌드할 때).

```sh
cd minwon-bot
go build -o minwon-bot ./cmd/minwon-bot     # 또는 ./scripts/build.sh 로 Windows/macOS/Linux 용을 한 번에
./minwon-bot                                  # 브라우저가 열립니다 (기본 http://127.0.0.1:8745)
```

옵션: `-port 9000`(포트 지정), `-no-browser`(브라우저 자동 열기 끄기). 터미널에서 실행하세요.

- **Windows**: `claude` 는 공식 설치 프로그램으로 설치한 `claude.exe` 를 쓰세요. npm 으로 설치한 `claude.cmd` 는 인자를 안전하게 넘길 수 없어 실패합니다. 이 경우 설정 화면의 "claude 실행 파일 경로"에 `claude.exe` 전체 경로를 입력하세요.
- **macOS**: 더블클릭 대신 터미널에서 실행해야 `claude` 를 찾습니다. 못 찾으면 설정에서 경로를 직접 입력하세요.

## 처음 쓰는 순서

1. **설정**에서 "연결 테스트"를 눌러 AI 연결을 확인합니다.
2. **설정 → 가릴 낱말**에 내 이름, 부대명 등을 적습니다. 종류를 붙이면 AI 가 문맥을 더 잘 이해합니다: `이름:홍길동`, `부대:제7사단`, `기관:국방부`.
   주민번호·전화번호·이메일·계좌번호는 자동으로 가려집니다.
3. **설정 → 내 문체**에 예전에 직접 쓴 글 3~5개를 붙여넣고 "문체 학습"을 누릅니다(선택).
4. **새 사안**에 사실관계와 원하는 결과를 적고 "초안 작성"을 누릅니다. AI 가 되물으면 답하고 다시 누르세요.
5. 초안을 고친 뒤 "저장하고 점검"으로 경고를 확인하고, 국민신문고에 **직접** 붙여넣어 제출합니다. 받은 접수번호를 "제출 기록"에 적습니다.
6. 기관 답변이 오면 "받은 답변 붙여넣기" → "답변 평가". 미흡하면 "재민원 초안 만들기".

## 개인정보와 보안

- 화면은 `127.0.0.1` 에서만 열리고, 다른 호스트 이름으로의 접근과 토큰 없는 요청은 거절합니다.
- AI 에 보내기 전에 개인정보가 `{{NAME_1}}`, `{{PHONE_1}}` 같은 자리표시자로 바뀌고, 결과는 이 PC 에서 되돌립니다. 원문은 AI 로 나가지 않습니다.
- 데이터는 설정 폴더에 저장됩니다: Windows `%AppData%\minwon-bot`, macOS `~/Library/Application Support/minwon-bot`, Linux `~/.config/minwon-bot` (`MINWON_HOME` 환경변수로 변경). 폴더는 본인만 읽을 수 있게(0700) 만듭니다.
- AI 호출은 `claude -p` 를 빈 임시 폴더에서 도구 없이(`--tools ""`), 세션 저장 없이 실행합니다.

## 제출 한도 (기본값, 설정에서 변경)

반복·자동 민원은 종결되거나 이용이 제한될 수 있다는 2024년 민원처리법 개정 보도가 있어 보수적으로 둡니다(조문과 시행일은 국가법령정보센터에서 직접 확인하세요).
하루 3건, 제출 사이 10분, 같은 사안 3회차부터 경고, 이전 글과 60% 이상 비슷하면 경고(90% 이상이면 차단 표시).
이 도구는 자동화 탐지를 피하는 기능(지문 위조, CAPTCHA 우회, 여러 계정 돌려쓰기 등)을 만들지 않습니다.

## 개발

```sh
go vet ./... && go test ./...                      # 단위·통합 테스트 (AI 는 가짜로 대체, 비용 없음)
go test -race ./...
go test -tags live ./internal/minwon -run Live -v  # 실제 AI 호출 점검 (구독/API 사용량이 듭니다)
MINWON_LIVE_BACKEND=api go test -tags live ...     # API 키 방식으로 점검
```

구성: `internal/llm`(구독·API 백엔드), `internal/minwon`(작성·평가·재민원·문체·가드, 프롬프트는 `prompts/*.txt`),
`internal/privacy`(가림/복원), `internal/store`(SQLite, cgo 없음), `internal/web`(화면과 API), `internal/config`.
