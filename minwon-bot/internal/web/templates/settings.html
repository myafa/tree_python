답변 후 자동 처리

답변이 기록되면 사람의 승인 없이 평가하고, 결과에 따라 재민원을 쓰거나 사안을 종결한 뒤 보고함(과 연결한 채널)으로 알려 드립니다. 사이트 연동: {{if .PortalName}}{{.PortalName}} — 재민원도 사이트에 자동 제출합니다.{{else}}없음 — 재민원은 초안까지만 자동으로 만들고, 직접 제출하셔야 합니다(보고함으로 알려 드립니다).{{end}}

자동 처리 규칙
  • 답변이 충분하면 종결, 다른 경로가 낫다고 판단되면 종결(다른 경로 안내를 보고에 담음).
  • 미흡하면 미흡한 항목만 다시 묻는 재민원을 씀. 같은 사안의 {{.Cfg.Limits.RepeatRound}}회차부터는 반복민원으로 종결될 수 있어 만들지 않고 종결·보고함.
  • 이전 글과 비슷하거나 본문에 개인정보가 있거나 욕설이 섞이면 자동 제출하지 않고 초안을 남긴 채 보고함.
  • 하루 한도·최소 간격에 걸리면 제출을 미루고 한도가 풀리면 이어서 처리함.
  • 추가 인증이 뜨거나 예상 밖 화면이면 우회하지 않고 이 사안의 자동 처리를 끄고 보고함.
  • 직접 고치거나 직접 만든 재민원 초안은 자동 제출하지 않음. 종결은 사안 화면의 '다시 열기'로 되돌릴 수 있음.
